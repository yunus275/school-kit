# Download Site

Empty page with one Download button that downloads `Aymen_Schoolboadddrd_EXE_Kit.zip`.

- `src/` – index.html, style.css, main.js
- `public/` – the zip file
- `dist/` – built output (what Vercel serves)

## Publish
1. Push to GitHub:
   git init && git add . && git commit -m "init" && git branch -M main
   git remote add origin <your-repo-url> && git push -u origin main
2. Vercel -> Add New Project -> import the repo -> Deploy (settings come from vercel.json).
